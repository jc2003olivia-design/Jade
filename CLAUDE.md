# Working rules for Claude

## Learn as you go — keep `LESSONS.md` current

Read `LESSONS.md` before starting any task, and follow what it says.

While working, add to `LESSONS.md` whenever you hit something that a note
would have prevented or made faster. That includes:

- **Mistakes** — anything you got wrong, whether Jade corrected you or you
  caught it yourself (wrong brand, wrong category, wrong price, wrong file,
  a step done out of order).
- **Gotchas** — tools, sites or commands that failed or behaved
  unexpectedly, and the workaround that worked.
- **Preferences** — anything Jade says she likes, dislikes, or wants done a
  certain way ("always…", "never…", "I prefer…").
- **Useful facts** — business details worth knowing next time: sizing,
  pricing patterns, platform rules, supplier or market info, file locations.

How to write an entry:

- Put it under the matching section; add a new section if none fits.
- One or two lines. Say what to do, not the story: "Skims bodysuits go
  under Tops, not Intimates", not "Last time I listed a bodysuit…".
- If an entry is wrong or outdated, fix or delete it rather than adding a
  second one that contradicts it.
- Add it right when it happens, not at the end, so it isn't forgotten.
- Commit `LESSONS.md` with the rest of the work so the next session has it.
- Tell Jade in one line when you've added a lesson.

Skip one-off details that won't matter again, and never write passwords,
logins, or customer personal info into the file.

# Titles

## Whatnot show titles

### Formula
`$1 (or $1 STARTS)` + `2–3 brand names` + `one emoji` + `(optional) theme`

- Put **$1 and the brand names first**. The feed cuts long titles off, so
  whatever's at the end may not show. Aim for about 45 characters.
- Use the same brands as that night's cover runners, so the title and cover match.
- One emoji per title, the same one every week for that show, so repeat buyers
  spot it: 🍂 Contemporary (fall), ✨ Contemporary 2, 💦 Activewear.
- Only say **NWT** or **sets** if most of the show really is NWT or sets.
- Keep the pattern the same every week. Only swap the brands and theme.

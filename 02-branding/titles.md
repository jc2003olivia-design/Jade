## Whatnot show titles
Formula: `$1 + SHOW NAME · size range · what's in it`. Keep the show name the same as
the cover so repeat buyers match them, and put the words buyers search for (brands,
"baby", item types) in the title. The title shows in follower notifications. **[Whatnot]**
